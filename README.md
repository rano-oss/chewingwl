# chewingwl

Zhuyin (Bopomofo) input method for Wayland (COSMIC), on `experimental/xx-im-preedit-start` until that stack lands on main.

Panel mode badge is **中 / 英**; source label is configured separately (e.g. **ㄅ**). Fullwidth is menu / Shift+Space.

## Alpha
- [x] Expanded list navigation
- [x] Multiple to single character select
- [x] Number key select
- [x] Shift language change

## Beta
- [x] Cursor accounting (no magic byte length)
- [x] Shift 中/英 mechanic
- [x] Wide / fullwidth Chinese
- [x] Clean state on deactivate/activate
